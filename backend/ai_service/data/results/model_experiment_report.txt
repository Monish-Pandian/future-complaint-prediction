15. WHY THE BEST MODEL WAS SELECTED
----------------------------------------
   The research objective is to identify future civic problems using a LIMITED
   verification budget. Therefore, the primary selection criteria are:
   - PR-AUC (robust to class imbalance)
   - Recall@K (ability to find true positives within limited budget K)
   - Calibration (probability estimates match actual frequencies)
   XGBoost achieves the best balance of PR-AUC and Recall@K on the TEST set,
   with well-calibrated probabilities suitable for ranking.

16. LEAKAGE OR METHODOLOGICAL CONCERNS
----------------------------------------
   - Temporal split strictly enforced: TRAIN (2020-2023), VALIDATION (2024), TEST (2025)
   - No test data used in training, feature engineering, or threshold selection
   - Validation set used ONLY for threshold selection and early stopping (XGBoost)
   - Target 'future_complaint' excluded from features
   - 'complaint_count' (current week count) excluded from features
   - All lag/rolling features use only T-1 information
   - No SMOTE/oversampling used; natural class distribution preserved
   - Categorical encoding fit only on training data
   - StandardScaler fit only on training data
   - No leakage detected
